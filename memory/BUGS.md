# BUGS.md — Bugs Conhecidos

> Consultar antes de criar novos componentes para evitar reintroduzir problemas.
> Atualizar status quando um bug for resolvido.

---

## Status possíveis
- 🔴 **Aberto** — não resolvido
- 🟡 **Em progresso** — sendo trabalhado
- 🟢 **Resolvido** — fechado (manter por 30 dias para referência)

---

## Formato

```
### [ID] Título do bug
**Status:** 🔴 Aberto | 🟡 Em progresso | 🟢 Resolvido
**Descoberto em:** YYYY-MM-DD
**Resolvido em:** YYYY-MM-DD (se aplicável)
**Componente afetado:** caminho/do/componente
**Descrição:** o que acontece
**Reprodução:** como reproduzir
**Causa raiz:** o que causou (preencher ao resolver)
**Solução:** o que foi feito para resolver
```
